First public preview of Homebrew CFD: a GPU lattice Boltzmann solver for external aerodynamics with a desktop application to set up, run and monitor cases. This is an early, Windows-only build. The solver is validated case by case (see `docs/DESIGN.md`); the application around it is new.

## Highlights

- **Desktop application:** setup tree, property forms with live validation (relaxation time, Mach number, cells, steps), 3D viewport with named, corner and orthographic views, autosave.
- **Run control:** the solver runs as a separate process with a console, a progress bar, live force-coefficient monitors and a clean Stop. Each run writes a self-contained folder: case, progress, results, coefficient history and solver log.
- **Case files:** versioned JSON with geometry by reference (NACA section or STL). Ships with the inverted NACA 4412 wing-in-ground-effect template.
- **Headless solve:** `HomebrewCFD.exe --solve case.json` runs a case without the interface.
- **Solver:** D3Q19 with regularized / TRT / BGK collision, WALE and Smagorinsky LES, Bouzidi curved walls, moving ground, rotating wheels, relaxation layers and per-part forces.

## Validation

The wing template reproduces the logged reference run exactly from the command line, the application and the installed executable: C_y −0.3368 (SE 0.0004), C_x 0.1144. The operating envelope (relaxation-time floor, resolution, blockage, Mach number, Reynolds number) and the validation cases are documented in `docs/DESIGN.md`.

## Requirements

- Windows 10 or 11, 64-bit.
- NVIDIA GPU with a current driver (CUDA). This build runs on CUDA only; other GPUs and CPU-only machines are not supported yet.
- About 1.5 GB of disk space.

## Install

1. Download `HomebrewCFD-0.1.0-setup.exe` and check its SHA-256 against `SHA256SUMS.txt`:
   `Get-FileHash HomebrewCFD-0.1.0-setup.exe -Algorithm SHA256`
2. Run the installer. It is not code-signed yet, so Windows SmartScreen will show "Windows protected your PC". Choose **More info → Run anyway** only if the checksum matches.
3. Start Homebrew CFD, then **File → New from template → wing_ground**, save the case, and press **F5**.

## Known limitations

- Windows and NVIDIA (CUDA) only. Backend selection, Linux and other GPU vendors are planned.
- Geometry editing in the interface is limited to the template's NACA section; STL parts can be set in case files but not yet imported through the interface.
- This release was built locally. Later releases will be built by GitHub Actions from tagged commits, with build-provenance attestation.
- Results are trustworthy for relative comparisons and trends, not as certification-grade absolute coefficients (see Accuracy expectation in the README).
