Hygiene and polish release: the first build made entirely by GitHub Actions, with checksums and build-provenance attestation, plus a reworked interface. No solver changes.

## Highlights

- **Ribbon interface:** Home, View, Run and Results tabs replace the menus and toolbar; every shortcut works on every tab.
- **Results tab:** full-size force-coefficient monitors with the last-run summary underneath. The x-axis is in flow-throughs, the warmup is shaded, and each curve shows its running mean (bold) over the raw samples (faint); the y-range follows the bulk of the data, so start-up spikes no longer flatten the curves.
- **Run state:** the summary shows Running, the status line shows Warmup or Averaging, and inputs and case loading are frozen during a run (the setup tree stays navigable).
- **Layout:** window size, pane splits and the console position are remembered between sessions; View → Reset layout restores the default. Pane dividers are now visible.
- **Messages:** status, console and summary messages start with a capital letter.

## Build and release

- Built by GitHub Actions from the tagged commit; a CPU smoke test runs the packaged solver on every build.
- `SHA256SUMS.txt` and a build-provenance attestation are published with the installer.
- Dependencies are pinned and audited (pip-audit, Dependabot). UPX compression is off, and the PyInstaller launcher is compiled from source in CI.
- `SECURITY.md` describes private vulnerability reporting and how to verify a download.

## Validation

The installer reproduces the logged reference run of the wing template exactly: C_y −0.3368 (SE 0.0004), C_x 0.1144.

## Requirements

- Windows 10 or 11, 64-bit.
- NVIDIA GPU with a current driver (CUDA).
- About 1.5 GB of disk space.

## Install

1. Download `HomebrewCFD-0.1.1-setup.exe` and check it, either against `SHA256SUMS.txt`:
   `Get-FileHash HomebrewCFD-0.1.1-setup.exe -Algorithm SHA256`
   or with the attestation:
   `gh attestation verify HomebrewCFD-0.1.1-setup.exe --repo JDavies101/Homebrew-CFD`
2. Run the installer. It is not code-signed yet, so Windows SmartScreen will show "Windows protected your PC". Choose **More info → Run anyway** only if the check passes.
3. Start Homebrew CFD, then **Home → New → wing_ground**, save the case, and press **F5**.

## Known limitations

- Antivirus: a few engines on VirusTotal, including Microsoft Defender (`Trojan:Win32/Wacatac.C!ml`, a machine-learning verdict), flag the unsigned application. This is a known false-positive pattern for PyInstaller applications; it has been reported to Microsoft as an incorrect detection. If Defender quarantines the application, verify the download as above and restore it. Code signing is planned for v0.2.0. Update 2026-10-02: Microsoft reviewed the detection and classified the file as not malware; v0.2.0 and later are code-signed (VirusTotal 0/66 on the signed test build).
- Windows and NVIDIA (CUDA) only.
- STL parts can be set in case files but not yet imported through the interface.
- Results are trustworthy for relative comparisons and trends, not as certification-grade absolute coefficients.
