Look and identity release: code-signed builds, a new icon and splash screen, a dark theme built from the icon palette, custom ribbon icons, and a safe default location for cases and runs. No solver changes.

## Highlights

- **Code signing:** the application and the installer are signed with Azure Artifact Signing under my name (Jake Davies); Windows shows a verified publisher instead of "Unknown publisher". Signing happens only in CI on release tags.
- **New icon and splash screen:** an inverted, cambered rear-wing section with streamlines from a computed potential-flow solution (panel method with the Kutta condition), not a drawing; a simplified version is used at 16-32 px. The splash screen appears immediately at start-up with the version.
- **Dark theme:** one navy palette taken from the icon across panels, inputs, monitors and status colors; ribbon tab names in Saira; the 3D viewport has a white background so the axes and geometry read clearly.
- **Ribbon icons:** a matching set of line icons replaces the standard Qt icons; the view buttons show which face of the domain they look at.
- **Default workspace:** cases are saved to and opened from Documents\Homebrew CFD Projects by default, and every run goes to its Runs folder, never the installation folder (an uninstall or upgrade could delete it).

## Build and release

- Built by GitHub Actions from the tagged commit, with the CPU smoke test, SHA256SUMS.txt and build-provenance attestation as in v0.1.1.
- HomebrewCFD.exe and the installer are signed and the signatures verified in CI before checksums are computed.
- Fonts (Saira, SIL Open Font License) are bundled.

## Requirements

- Windows 10 or 11, 64-bit.
- NVIDIA GPU with a current driver (CUDA).
- About 1.5 GB of disk space.

## Install

1. Download `HomebrewCFD-0.2.0-setup.exe` and check it, either against `SHA256SUMS.txt`:
   `Get-FileHash HomebrewCFD-0.2.0-setup.exe -Algorithm SHA256`
   or with the attestation:
   `gh attestation verify HomebrewCFD-0.2.0-setup.exe --repo JDavies101/Homebrew-CFD`
2. Run the installer. It is signed: the Windows prompt shows **Jake Davies** as the verified publisher. Because the signing certificate is new, SmartScreen may still show "Windows protected your PC" until the certificate builds reputation; check the publisher, then choose **More info → Run anyway**.
3. Start Homebrew CFD, then **Home → New → wing_ground**, save the case, and press **F5**. The case and its run folder go to Documents\Homebrew CFD Projects.

## Known limitations

- SmartScreen reputation: the signing certificate is new, so the warning may still appear on first downloads; it fades as downloads accumulate, and the pattern has been reported to Microsoft.
- Windows and NVIDIA (CUDA) only.
- STL parts can be set in case files but not yet imported through the interface.
- Results are trustworthy for relative comparisons and trends, not as certification-grade absolute coefficients.
