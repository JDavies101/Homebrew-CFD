Geometry and pre-run checks: STL import with a size and watertight report, a full-window start page that sets up a study from the problem, the study and the real flow, a memory and run-time estimate, a voxel and boundary-link preview built by the solver itself, validated templates, project folders, and a user manual. No changes to the solver's physics.

## Highlights

- **Start page:** the app opens on a new-study page. Choose the problem (free stream, ground effect with a static or moving floor, rotating wheel) and the study (averaged forces or unsteady), give the real speed, body length and fluid, and pick a resolution; every field has a default. A live 3D preview and a verdict show the physical and resolved Reynolds number, tau, Mach, grid size, GPU memory and run time as the answers change. Recent cases and templates are listed on the same page.
- **STL import:** STL files (binary or ASCII) can be imported from the start page or from Home > Import STL. Each part reports its size in cells and in the STL's own units with the scale between them, warns when it is under 10 cells across or outside the domain, and checks the mesh is watertight (open, flipped and non-manifold edges).
- **Pre-run estimate:** GPU memory of the solver's fields, computed field by field and checked against the solver's own allocation, in red when it would not fit the card; run time from the cells, the steps and this machine's measured throughput after its first finished run.
- **Voxel preview:** View > Voxels builds the geometry exactly as the solver will, in its own process, and shows the solid cells and the Bouzidi wall points colored by the wall fraction q. A part whose interpolated wall would be silently missing is flagged in red.
- **Templates:** Ahmed body, sphere and spinning cylinder join the wing in ground effect and an empty 3D case. Each reproduces its logged reference run (see Validation).
- **Projects:** Save as creates one folder per project, holding the case, a geometry folder with imported STLs copied in, the runs and an exports folder. Paths inside the project are stored relative, so a project can be moved or shared as a whole. Cases saved with earlier versions still open and run.
- **Manual:** Help > Manual (F1) opens the user manual: introduction, getting started, two tutorials (wing in ground effect, importing an STL) and a reference of every setting.

## Fixes

- The console no longer repeats the end of a line now and then (the solver log was read with Windows line-ending translation, which shifted the read position).
- The monitor plots now run to the end of the run; the last samples before the end were never written to the live file.

## Validation

The self-reproduction gates for this release: each template, run from the app, reproduces the logged run of the example it was built from (runs 171-174).

| Template | This release | Logged reference run |
|---|---|---|
| Ahmed body, 25° slant, H = 32 | Cd 0.6996 (SE 0.0019) | run 72: 0.6996 (SE 0.0019), identical |
| Spinning cylinder, Re 100, ωR/U = 1 | Cd 1.1644, Cl −2.652 | run 155: identical |
| Sphere, Re 50 | Cd 1.6229 | run 66: 1.6228 (series mean against end value) |

These show that the templates rebuild the validated cases exactly. Comparison of each case with published experiments and correlations, with full references, is planned before version 1.0.

The signed installer is checked against the wing template's reference run: C_y −0.3368 (SE 0.0004), C_x 0.1144.

## Requirements

- Windows 10 or 11, 64-bit.
- NVIDIA GPU with a current driver (CUDA).
- About 1.5 GB of disk space.

## Install

1. Download `HomebrewCFD-0.3.0-setup.exe` and check it, either against `SHA256SUMS.txt`:
   `Get-FileHash HomebrewCFD-0.3.0-setup.exe -Algorithm SHA256`
   or with the attestation:
   `gh attestation verify HomebrewCFD-0.3.0-setup.exe --repo JDavies101/Homebrew-CFD`
2. Run the installer. The Windows prompt shows **Jake Davies** as the verified publisher. SmartScreen may still warn until the certificate builds reputation; check the publisher, then choose **More info → Run anyway**.
3. Start Homebrew CFD. On the start page, double-click **wing ground** under Templates, Save as a project and press **F5**. Help > Manual (F1) walks through it.

## Known limitations

- Results are trustworthy for relative comparisons and trends, not as certification-grade absolute coefficients.
- High Reynolds numbers are limited by the grid; the case shows the resolved value and says when it is capped.
- The Ahmed body has staircase walls only; the rotating wheel problem has no wheel body yet (the spinning cylinder is the validated rotating case).
- Imported STLs cannot yet be rotated in the app; orient them before export.
- Windows and NVIDIA (CUDA) only. SmartScreen reputation for the signing certificate is still building.
